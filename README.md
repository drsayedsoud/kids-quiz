# مسابقات المرحلة الابتدائية

تطبيق ويب (PWA) لمسابقات تلاميذ الحضانة والمرحلة الابتدائية، منسوخ من مشروع `new-quiz-quran` ومقتصر على قسم الأطفال.

- **الصفحة الرئيسية** `index.html`: قسم واحد «المرحلة الابتدائية» بثلاث طرق للعب (لوحدك، مع الأصحاب، الدخول بكود).
- **الصفوف**: حضانة (`kids_1`)، ثاني ابتدائي (`kids_2`)، ثالث ابتدائي (`kids_3`)، الحصالة بفلوس (`kids_piggy` = أسئلة `kids_2`). أولى ورابع وخامس وسادس ابتدائي بطاقات معطّلة «قريباً».
- **المفاتيح الداخلية** للأقسام لم تتغير حتى تبقى الغرف ولوحة الشرف متوافقة مع التطبيق الأصلي؛ الأسماء المعروضة فقط تغيّرت.
- **Firebase**: نفس المشروع `newclinic1-f25d4` ونفس قاعدة البيانات (`firebase-init.js` بلا تغيير). أضف دومين النشر الجديد إلى Authentication → Authorized domains.
- **الأسئلة**: ملفات `data/kids_*.zip` فقط مع `data/manifest.json`.
- **المظهر**: سمة الأطفال الهادئة في `kids-theme.css` و`kids-theme.js` (ألوان أقل تشبعاً، بلا سحب أو بالونات أو تدرجات متحركة).
- **الكاش**: `sw.js` باسم `kids-quiz-v9`؛ ارفع الرقم عند كل نشر يغيّر الملفات.
- **إعدادات اللعب الفردي** (صفحة ملفي، على الجهاز فقط): `kids_timer` = `auto` (الحضانة بلا مؤقّت والصفان الثاني والثالث بمؤقّت) أو `on` أو `off`، و`kids_read` = `on` (قراءة كل سؤال تلقائياً) أو `off` (عند الضغط على السماعة فقط).

## التشغيل محلياً

```bash
npx --yes http-server . -p 5173 -c-1
```

ثم افتح `http://localhost:5173`.
